# School Enrollment Management System

### A Workflow Automation Project by E and E Icons

## Project Overview

The School Enrollment Management System is a workflow automation prototype designed to simplify how schools receive, organize, and respond to student enrollment applications.

It connects digital application forms, record management, WhatsApp notifications, and email communication into one automated workflow.

## The Problem

Manual enrollment processes can involve repetitive data entry, delayed notifications, disorganized application records, and unnecessary follow-up by parents or applicants.

This project demonstrates how workflow automation can help reduce these challenges.

## How It Works

1. **Online Application:** A parent or applicant submits an enrollment form.
2. **Workflow Automation:** Make.com processes the submitted information.
3. **Record Management:** Application details are saved in an organized Airtable database.
4. **School Notification:** The designated school contact receives a WhatsApp notification.
5. **Email Notification:** The school receives an email about the new application.
6. **Applicant Confirmation:** The parent or applicant receives an automated email acknowledging receipt.

## Technology Stack

- Make.com – Workflow automation and integration
- Google Forms – Online application collection
- Airtable – Application record management
- Twilio WhatsApp – Automated WhatsApp notifications
- Gmail – Automated email notifications

## Key Benefits Demonstrated

- Digital collection of enrollment applications
- Organized application records
- Automated school notifications
- Automated applicant confirmation emails
- Reduced repetitive manual communication
- Improved awareness of new applications

## Project Status

Working prototype. The end-to-end workflow has been tested successfully.

This project is a demonstration of practical workflow automation and system integration. It is not presented as a live deployment at a paying school.
